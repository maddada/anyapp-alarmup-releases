# Alarm Up

<img src="icon.png" alt="Alarm Up" width="96" height="96">

An Android app made with Kiwimake.

Latest version: **1.0** (build 5), published 2026-11-20.

## Install

1. On your Android phone, open [alarmup.apk](https://github.com/maddada/anyapp-alarmup-releases/releases/latest/download/alarmup.apk).
2. Android asks you to allow installing apps from your browser: allow it, then tap Install.
3. From then on the app tells you when a new version is out. Tap the notification to update.
